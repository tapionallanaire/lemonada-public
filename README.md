# Lemonada

Lemonada is an Android frontend for 4:3 handhelds such as the Retroid Pocket Classic and Mini. It is a fork of [Calamansi](https://github.com/tapionallanaire/calamansi-public) focused on NES, SNES, Mega Drive, Game Boy, Game Boy Color, Game Boy Advance, PlayStation, Saturn, Dreamcast, GameCube and PlayStation 2 under one HOME screen, with save sync through a PC running Syncthing.

Downloads are on the [Releases](https://github.com/tapionallanaire/lemonada-public/releases) page. Each release lists its APK and a `SHA256SUMS` file; check downloads with `sha256sum --check SHA256SUMS`. Lemonada updates itself from this page.

Lemonada does not include BIOS files or games. You must supply your own, dumped from hardware you own.
